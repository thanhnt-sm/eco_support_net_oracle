# DataGuard SQL-to-C# Visibility & Traceability Plan Execution

## Decisions & Changes

1. **Enhanced `ScanSummary.ToJson()` & CLI `scan` Command**:
   - Extended `ScanSummary.ToJson()` schema in `src/DataGuard.Core/Reporting/MappingReport.cs` with query location (file path and 1-based line number), `mappingStatus` (`matched`, `partial`, `unmapped`, `untyped`), and suggested `action` (`shape-check`, `select-star-warning`, `untyped-query`).
   - Implemented `dataguard scan` CLI command in `src/DataGuard.Cli/Program.cs` accepting `--project`, `--format` (`text` or `json`), `--output`, `--verbose`, and `--progress`, reporting accurate file counts via `ProjectCSharpSqlSource.DiscoverSourceFiles`.
2. **Pass 5 in `ProjectCSharpSqlSource.cs`**:
   - Added Pass 5 to detect unreferenced `const` and `static readonly` SQL strings, avoiding duplicate untyped entries when already referenced in typed call sites.
3. **`dataguard.sqlQueriesView` Tree Provider**:
   - Created `src/DataGuard.VSCode/src/ui/sql-queries-tree-provider.ts` grouping discovered queries by source file with visual operation icons, mapping status badges, and interactive click-to-jump navigation.
   - Contributed view under `dataguard-explorer` and registered commands `dataguard.scanProject`, `dataguard.refreshQueries`, and `dataguard.verifyShape`.
4. **Interactive SQL ↔ C# Mappings Dashboard Tab**:
   - Added tab navigation to `DataGuardDashboardPanel` (`dashboard-view.ts` and `dashboard-panel.ts`) with searchable query table, status badges, matched/unmapped property lists, and jump-to-source click handling while strictly preserving nonce-based CSP.
5. **Live Schema Provider Dummy Parameter Binding & `verify-shape`**:
   - Fixed `OracleLiveQuerySchemaProvider.cs` and `PostgreSqlLiveQuerySchemaProvider.cs` by extracting parameter tokens (`:param`, `@param`, `$1`) and binding dummy `DBNull.Value` parameters, preventing `ORA-01008` and `42P02` exceptions under `CommandBehavior.SchemaOnly`.
   - Wired `dataguard verify-shape` CLI command for live DB result set shape verification against C# models.
6. **Red-Team Dialect & Shape Engine Hardening**:
   - Replaced non-greedy `SelectFromRegex` in `ColumnShapeMatchRule.cs` with parenthesis-depth-aware `ExtractTopLevelSelectClause` and `SplitTopLevelClauses`, resolving truncation bugs when subqueries appear in the SELECT clause and capturing aliases on functions (e.g. `GROUP_CONCAT(...) as order_ids`).
   - Removed `"CONCAT"` from `OracleOperators` in `OracleDialectChecker.cs` to eliminate false-positive substring matches on standard SQL functions.
   - Cleaned up rule registrations in `ProviderRuleCatalog.cs` and `GoldenCorpusTests.cs` so `OracleSyntaxInNonOracleContextRule` (DG010) targets non-Oracle providers rather than Oracle itself.
