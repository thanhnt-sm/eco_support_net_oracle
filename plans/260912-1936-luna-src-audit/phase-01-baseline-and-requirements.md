# Phase 1: Baseline and requirements

## Overview

Chốt baseline và danh mục cam kết cho các worker source. Xem [plan](plan.md).

## Implementation Steps

1. Đọc governance và git rules; ghi commit, WIP, tracked/untracked inventory.
2. Luna plans/research và docs đọc theo lô, phân loại lịch sử/định hướng/hiện hành.
3. Gửi danh mục yêu cầu có file:dòng cho worker source; mỗi file có một owner.
4. Tài liệu discovery cũ chỉ là đầu mối; số test cũ không thay thế verification mới.

## Success Criteria

- Inventory có đủ src/plans/research/docs và phân biệt generated/binary.
- Danh mục yêu cầu bàn giao được cho source workers; coverage chi tiết được kiểm tra lại ở phase 3.
