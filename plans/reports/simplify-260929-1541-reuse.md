## Suspects checked — no existing helper covers them

- **`SafeWritablePath.IsLink` (`src/DataGuard.Cli/SafeWritablePath.cs:72-90`)**: not new code — the old `Program.cs` `IsLink` body relocated. Its extra `GetAttributes … ReparsePoint` probe (flags non-symlink reparse points) is a deliberate superset of `PreCommitHookInstaller.IsSymbolicLink` (`src/DataGuard.Cli/Hooks/PreCommitHookInstaller.cs:457`) and of the `File.ResolveLinkTarget(…, returnFinalTarget: false)` idiom in Core (`PluginAdmission.cs:142`, `SupplyChainVerifier.cs:109`, `PackageLockReader.cs:121`). Not a reuse candidate.
- **`SafeWritablePath` ancestor walk vs `OfflineManifestWriter.HasReparsePointAncestor` (`src/DataGuard.Cli/OfflineManifestWriter.cs:94-118`, same assembly)**: stop conditions differ — the writer stops at the OS temp alias (`IsAllowedTempAlias:122`), the new policy stops at the workspace root. For `D:\reports\<junction>\sub\x.sarif` (outside both) one allows, the other rejects. Different policy, not a duplicate. Same for `PluginAdmission.cs:169`, `CredentialManager.cs:365-390`, `IAuditLogger.cs:181`.
- **Env-var name matching (`IdeSafeEnvironment.cs:55-76`)**: `ZeroTrustCredentialProvider.GetEnvironmentVariableName` (`:196`) is a private instance method; `VAULT_TOKEN` (`:275`) and `ConnectionStrings__*` (`AutoDetectionEngine.cs:299-300`) are literals. No shared constant exists to call; only option is to create one (`DATAGUARD_` prefix) — out of scope for a reuse finding.
- **Host masking (`live-database-confirmation.ts:10-64`)**: `security.ts` has redaction only (`URI_CREDENTIALS:6` strips the password, never extracts the host); `ui/redaction.ts` likewise. Nothing to reuse.
- **YAML step-walking (`scripts/check-workflow-policy.py`)**: no other script in `scripts/` parses workflows (`verify_*.sh`, `generate_claim_occurrences.py` are unrelated).
- **stderr classification**: `ProgressStreamReader.cs:66-72` already calls `CliArgumentBuilder.IsIdeSafeUnsupportedMessage` / `IdeSafeActiveLine`; no duplication. The `ide-safe: active` literal exists once per host (`IdeSafePolicy.ActiveLine`, `CliArgumentBuilder.IdeSafeActiveLine`, `IDE_SAFE_ACK_LINE`) because VS (net472, zero ProjectReferences) and VSCode cannot reference `DataGuard.Cli`.
- **`isLiveDatabaseCommand` vs `expectsSarif`/`expectsSummary` (`extension.ts:434-435`)**: scattered command classification is an altitude issue, not reuse of an existing helper.
- **`RegexMatchTimeoutStartup`, `ProjectCSharpSqlSource.MaxSqlLiteralLength`, `ProgressPump`, `PublishGate`, `check-workflow-policy.py` expression splitter**: no prior equivalents in the tree.
